# Security policy

Only the latest release of herder is supported.

Use [GitHub private vulnerability reporting](https://github.com/Shaance/herder/security/advisories/new) to report a vulnerability. The maintainer responds on a best-effort basis.

Include the affected herder version, macOS version and executor version if relevant, steps to reproduce, and the potential impact. Redact credentials and sensitive data from any logs or output you attach.
